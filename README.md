# fe-angular-bootstrap-starter

A minimal **Angular (standalone components) + TypeScript + Bootstrap 5** starter for DayZer0 frontend briefs.

## Stack

- Angular 20 (standalone components, no NgModules)
- TypeScript (strict)
- Bootstrap 5 (imported in `src/styles.css`)

## Getting started

```bash
npm install
npm start
```

Then open http://localhost:4200. You should see the "It runs" starter screen styled with Bootstrap.

To produce a production build:

```bash
npm run build
```

Output lands in `dist/app`.
